# Архитектура ATLAS

ATLAS — локальный прототип для одного доверенного рабочего пространства. React отвечает за навигацию и проверку результатов, FastAPI — за обработку документов и анализ, SQLite — за сохранение данных. В Docker клиент раздаётся Nginx; `/api` проксируется в FastAPI. Отдельная PostgreSQL из исходного шаблона заменена на реально используемую SQLite: для хакатонного сценария не нужен отдельный сервис базы.

## Поток данных

```text
DOCX / PDF / XLSX / TXT / CSV
  → извлечение точного текста и адреса фрагмента
  → автоматическая разметка + ручные исправления
  → GPT: извлечение подразделений и функций
  → GPT: смысловые соответствия и потенциальные риски
  → проверка JSON, полноты и идентификаторов источников
  → таблица функций + изменения подразделений + замечания
  → проверка сотрудником → HTML / Markdown / CSV / печать PDF
```

Анализ выполняется только через GPT-5. Без API-ключа запуск запрещён; локальной подмены нет. Создание демонстрационного проекта загружает документы без анализа и без расхода кредитов. GPT-5 запускается по явному нажатию кнопки.

## Серверные модули

| Модуль | Ответственность |
| --- | --- |
| `parser.py` | Извлечение текста, ограничение размера, адреса фрагментов, исходная разметка |
| `ai.py` | OpenAI Responses API, строгие JSON-схемы, обработка отказов и проверка ссылок |
| `analysis.py` | Сопоставление, источники, классификация изменений, статистика |
| `storage.py` | Транзакции SQLite, сериализация документов и результатов |
| `main.py` | API, загрузка, фоновые задания, история, решения проверяющего |
| `report.py` | Экспорт с экранированием HTML и защитой CSV от формул |

## Прослеживаемость

У фрагмента есть стабильный ID внутри документа. Ссылка на источник состоит из ID документа и ID фрагмента. Цитаты берутся из сохранённого извлечённого текста, а не генерируются моделью. DOCX использует номер абзаца, PDF — страницу и строку, XLSX — лист и строку. Номер пункта сохраняется, если он присутствует в извлечённом тексте.

GPT возвращает только соответствия существующих ID и текст объяснения. Сервер проверяет, что все исходные функции учтены, все ссылки существуют и риск имеет минимум два источника. При извлечении функции модель выбирает ID подразделения из ограниченного JSON Schema enum (или const для одного варианта). Каталог содержит названия из исходных заголовков (до 180 символов); имя файла доступно только при отсутствии заголовков. Сами названия не генерируются. Заголовок всегда закреплён за своим названием и не считается функцией; ручная разметка имеет приоритет. Если заголовки не обнаружены, сохраняется предупреждение о названии из файла. Необычные заголовки можно уточнить вручную. Эти проверки предотвращают вымышленные названия и ссылки, но не гарантируют правильность смыслового вывода: он подлежит проверке человеком.

Ручная разметка имеет приоритет над GPT. Изменение или удаление документа сбрасывает текущий результат и увеличивает редакцию проекта. История успешных запусков сохраняется. Во время анализа изменение документов и решений заблокировано транзакционной проверкой состояния. При перезапуске сервера незавершённые задания переходят в состояние ошибки и могут быть запущены повторно.

## GPT

Модель закреплена в коде: `gpt-5`; `OPENAI_MODEL` не используется. Используется `POST /v1/responses`, `text.format=json_schema`, `strict=true`, `store=false`, `reasoning.effort=low`. Один запрос на разметку каждого документа и один на сопоставление функций. При пропусках, повторах или неверных ID разметки выполняется одна повторная проверка. Использованные токены, включая повторную проверку, сохраняются в успешном результате.

Источник контракта API: [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs), [GPT-5](https://developers.openai.com/api/docs/models/gpt-5).

Ошибки 401, 429, недоступная модель, неполный ответ и ошибки в ссылках завершают запуск с понятным сообщением. Они не маскируются локальными результатами. Секрет не возвращается клиенту и не записывается в логи приложения.

## Ограничения и дальнейшее развитие

- Прототип без многопользовательской авторизации; Docker-порты доступны только на loopback. Перед внешним размещением нужны аутентификация, изоляция проектов, TLS и контроль доступа.
- SQLite и фоновые задачи FastAPI рассчитаны на один серверный процесс. Для масштабирования: PostgreSQL, очередь задач и отдельные worker-процессы.
- До 10 МБ/файл, 40 документов/проект, 600 функций/анализ, 150 страниц/PDF. Для GPT: 450 абзацев и 160 000 символов/документ, 240 000 символов функций/сопоставление.
- Сканам необходим внешний OCR. Автоматическая нумерация Word может отсутствовать в извлечённом тексте: тогда остаётся адрес абзаца. Сложные PDF-колонки и таблицы требуют проверки разметки.
- Лексическое сходство используется только как справочная метрика ближайшего фрагмента, не для принятия соответствий или выявления рисков.
- Карта структуры отражает преемственность названий и функций, а не юридически подтверждённую иерархию или факт создания подразделения.
- Внешние нормативные проверки и бенчмаркинг операторов не входят в текущий прототип.
